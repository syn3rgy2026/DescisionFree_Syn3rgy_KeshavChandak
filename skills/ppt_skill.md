# PowerPoint Skill

> **Owner:** Person 3

## Description

This skill enables the agent to create professional, multi-slide PowerPoint
presentations (.pptx) with themed styling, multiple layout types, and
structured content.

**IMPORTANT:** The following tools are REGISTERED and AVAILABLE in the runtime.
They are real, callable functions — DO NOT say they are unavailable. Call them directly.

## Available Tools (all registered, all callable)

### Primary Tool
- **`create_presentation(filename, title, slides_data, theme, subtitle, author)`**
  Creates a complete multi-slide deck from structured data. Supports bullet,
  section, text, comparison, and image slide types.
  THIS IS A REGISTERED TOOL. Call it directly like: `create_presentation(filename="output/deck.pptx", title="My Title", slides_data=[...], theme="default")`

### Helper Tools
- **`create_quick_ppt(filename, title, bullet_points, theme)`**
  Fast 3-slide deck (title, bullets, thank-you). Use for simple requests.
- **`add_slide_to_ppt(filepath, slide_type, heading, content)`**
  Append a slide to an existing .pptx file.
- **`list_ppt_themes()`**
  Show available colour themes.

## Trigger Conditions

Use this skill when the user says any of:

## Instructions — FOLLOW THIS EXACT ORDER

### Step 1 — Understand the topic and scope
- Ask clarifying questions only if the topic is truly ambiguous.
- If the user provides a clear topic, proceed immediately.
- Decide how many slides are needed (5–10 is typical for most requests).

### Step 2 — Plan the slide structure
Before calling any tool, outline the slides in your reasoning:
```
Slide plan:
  1. Title slide (auto-generated by the tool)
  2. Section: Introduction
  3. Bullet: Key Points
  4. Text: Deep-dive paragraph
  5. Comparison: Before vs After (if relevant)
  6. Thank-you slide (auto-generated by the tool)
```

### Step 3 — Build slides_data and call create_presentation

Build a Python list of dicts called `slides_data`. Each dict MUST have a `type` key.

**Bullet slide** (most common):
```python
{"type": "bullet", "heading": "Key Findings", "bullets": ["Point 1", "Point 2", "Point 3"]}
```

**Section divider** (use between major sections):
```python
{"type": "section", "heading": "Part 2: Analysis", "subtitle": "A deeper look"}
```

**Text slide** (for longer paragraphs):
```python
{"type": "text", "heading": "Executive Summary", "body": "Full paragraph text here..."}
```

**Comparison slide** (two columns):
```python
{
    "type": "comparison",
    "heading": "Plan A vs Plan B",
    "left_title": "Plan A",
    "left_items": ["Low cost", "Slower"],
    "right_title": "Plan B",
    "right_items": ["Higher cost", "Faster"]
}
```

**Image slide** (include a local image):
```python
{"type": "image", "heading": "Architecture Diagram", "image_path": "output/diagram.png", "caption": "System overview"}
```

### Step 4 — Choose a theme
Pick the most appropriate theme:
- `default`   — Clean white, blue accents (general purpose)
- `dark`      — Dark background, cyan accents (tech / modern)
- `corporate` — Light grey, navy + red (business / formal)
- `creative`  — White, purple/pink/orange (marketing / design)

### Step 5 — Call the tool

**CRITICAL: This is a registered tool. Call it DIRECTLY. Do NOT try to import it.**

```python
slides_data = [
    {"type": "section", "heading": "Introduction", "subtitle": "Setting the stage"},
    {"type": "bullet", "heading": "Key Points", "bullets": ["Point 1", "Point 2", "Point 3"]},
    {"type": "text", "heading": "Summary", "body": "Detailed paragraph here..."},
]

result = create_presentation(
    filename="output/my_deck.pptx",
    title="Presentation Title",
    slides_data=slides_data,
    theme="default",
    subtitle="Subtitle here",
    author="Synergy Agent"
)
print(result)
```

For simple presentations with just bullet points, use:
```python
result = create_quick_ppt(
    filename="output/my_deck.pptx",
    title="Presentation Title",
    bullet_points=["Point 1", "Point 2", "Point 3"],
    theme="default"
)
print(result)
```

### Step 6 — Report the result
Tell the user:
- The file path where the .pptx was saved
- How many slides were created
- Which theme was used

## CRITICAL RULES

1. **ALWAYS save to the output/ directory** — e.g. `output/my_deck.pptx`
2. **NEVER create empty presentations.** Every deck must have at least one content slide.
3. **Keep bullet points concise** — max 7 bullets per slide, each under 15 words.
4. **Use section slides** to break up decks with more than 5 content slides.
5. **Pick a theme that matches the tone** — use `dark` for tech, `corporate` for business, etc.
6. **If the user wants to add slides later**, use `add_slide_to_ppt` instead of recreating the whole deck.
7. **NEVER say "I can't create PowerPoint files"** — the PPT tools ARE AVAILABLE AND REGISTERED.
8. **NEVER try to import the tools** — they are already available as callable functions.
9. **Verify the file exists** after creation using `list_files` or `read_file`.

## Output Format

Always include in your final answer:
- File path to the .pptx
- Number of slides created
- Theme used
- A brief summary of the slide structure
